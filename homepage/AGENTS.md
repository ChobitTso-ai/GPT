# GPT 首頁維護規則

- 正式來源：`ChobitTso-ai/GPT`；本對話只負責首頁與共用導覽。
- 方向：Monkey Grove 類型的小島探索，保留角色走動、直接點建築、探索清單三種入口，且指向同一個主題。
- 小島與建築使用自行製作的幾何模型，不複製參考網站素材。
- 全部 UI 使用繁體中文；程式保留 Tso KY 署名與版本。
- `index.html`、`homepage/island.js`、`homepage/island.css` 由首頁對話唯一維護。
- 中國歷史互動書由其專用對話維護 `chinese-history/`。首頁對話不改互動書內容。
- 使用者已於2026-11-26授權首頁部署完成後請歷史書對話串接；該對話可在互動書確認上線後，只修改 `homepage/course-links.js` 的 `history` 相對網址，勿修改其他首頁檔案。
- 課程網址相對於首頁，例如 `./chinese-history/`；未完成上線時保持 `null`，不產生無效入口。
- 不把瀏覽器手機尺寸模擬視為實體手機或兒童試玩驗收。

- 2026-11-26 使用者糾正：首頁小島必須能拖曳旋轉；避免大面積名稱牌遮住建築，預設採小圖示，名稱僅在滑過、鍵盤聚焦或走近時顯示。
- 旋轉視角後，角色的方向控制須跟畫面方向一致；拖曳不能觸發建築點擊，並保留「轉回正面」。
